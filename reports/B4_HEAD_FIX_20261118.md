## Dynamic-posture metric (added 2026-11-18, Jamie's request)

Beyond the neutral 8-second gate, posture is measured DYNAMICALLY as the
percentage of decision windows the head/chest spend inside a reasonable
range, per replayed episode set (whole episodes, not endpoints; stochastic
sampling exactly as trained; process-local head-inertial override re-creates
the pre-B4 "historical rig" for before/after rows without touching the
corrected asset on disk):

- `head_rel_infrac` — fraction of windows with |head_pitch (relative to the
  chest)| ≤ 0.35 rad / ≤ 0.6 rad
- `head_world_up_frac` — fraction of windows with the head's world up-vector
  ≥ 0.9 / ≥ 0.8 (the fall rule's 0.5 threshold is far stricter, so both bands
  are reported rather than one arbitrary "reasonable" cutoff)
- `chest_infrac` — fraction of windows with |chest tilt| ≤ 0.35 / ≤ 0.6 rad
  (spine_L2 qpos IS the chest's world tilt: the pelvis carries no pitch dof)

Trainer-side telemetry does not record head pose (untouched by contract), so
the dynamic metric is measured on checkpoint replays at the same points in
the ladder for every comparison row.
